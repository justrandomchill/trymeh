12.1 Index invers pentru documente text
Enunt
Sa se calculeze indexul invers pentru un set de documente text. Map returneaza <word, {document_id: 1}> (document_id = numele documentului). Reduce sorteaza perechile aceluiasi cuvant si emite <word, {document_id_i: count_i, ...}>.

#!/usr/bin/env python3
import sys, os, re

for fname in os.listdir("input"):
    doc_id = fname
    with open(os.path.join("input", fname), encoding="utf-8", errors="ignore") as f:
        for line in f:
            for word in re.findall(r"[a-zA-Z]+", line.lower()):
                print(f"{word}\t{doc_id}")

#!/usr/bin/env python3
import sys
from collections import defaultdict

current_word = None
docs = defaultdict(int)

for line in sys.stdin:
    word, doc = line.strip().split("\t")
    if current_word and word != current_word:
        print(f"{current_word}\t{dict(docs)}")
        docs = defaultdict(int)
    current_word = word
    docs[doc] += 1

if current_word:
    print(f"{current_word}\t{dict(docs)}")

12.2 Index invers pentru URL-uri
Enunt
Utilizând algoritmul Map-Reduce (implementarea cu stdin/stdout), să se calculeze indexul invers pentru un set de URL-uri. Funcția de mapare va parsa conținutul fiecărei pagini web (se pot folosi modulele requests și BeautifulSoup) și va returna perechi de forma <word, {URL: 1}>, unde valoarea 1 reprezintă o apariție a cuvântului pe pagina respectivă. Funcția de reducere primește toate perechile, sortează perechile corespunzătoare aceluiași cuvânt și emite o pereche de forma <word, {URL_i: count_word_in_URL_i, ...}>.

#!/usr/bin/env python3
import requests, re
from bs4 import BeautifulSoup

URLS = [
    "https://en.wikipedia.org/wiki/Distributed_computing",
    "https://en.wikipedia.org/wiki/MapReduce",
]

for url in URLS:
    try:
        html = requests.get(url, timeout=10).text
        text = BeautifulSoup(html, "html.parser").get_text()
        for word in re.findall(r"[a-zA-Z]+", text.lower()):
            print(f"{word}\t{url}")
    except Exception as e:
        print(f"# eroare {url}: {e}", file=__import__('sys').stderr)
